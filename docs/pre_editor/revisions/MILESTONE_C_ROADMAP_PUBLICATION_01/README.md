# Accepted Milestone C roadmap publication snapshot 01

This is the explicit Git publication source for the accepted seven-phase Physics
Milestone C roadmap and its bounded governance publication bridge. Preparation
does not imply publication or Phase26 authorization. The accepted technical
scope is preserved byte-for-byte in [roadmap/PRE_EDITOR_PLAN.md](roadmap/PRE_EDITOR_PLAN.md).

The [manifest](publication-manifest.json) declares every publication path, mode,
SHA256 and local source binding. The [spec](publication-spec.json) binds that
manifest and the fixed repository, branch, remote, parent and governance tag.
The [receipt](receipt.json) binds the payload excluding itself; it does not claim
its own containing commit identity. The private transaction journal records the
actual commit/tree/tag and verified remote completion later.

Copies under governance/ and tooling/ preserve exact local installation bytes.
These are reproducible reference sources, not instructions to overwrite local
state on checkout. Ignore rules are unchanged. Private journals, local active
state, index inventories, raw historical evidence, runtime outputs and unrelated
Owner work are intentionally outside this publication. Source-only roadmap
references to local historical evidence remain provenance references; this
snapshot does not claim to reproduce that evidence campaign.

Read [REVIEW.md](REVIEW.md) for the bridge design and
[PUBLICATION_PROCEDURE.md](PUBLICATION_PROCEDURE.md) for the future transaction.
The local remediation READY review retains exact offline evidence identities.
Original Phase25 approval and all earlier dispositions remain immutable.
